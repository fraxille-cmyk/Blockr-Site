# Blockr — marketing site

The public marketing site and legal documents for [Blockr](https://blockr.online),
the iOS screen-time companion. The app is live on the App Store:
[Blockr: Stop Scrolling](https://apps.apple.com/app/blockr-stop-scrolling/id6764129473).

- [`index.html`](index.html) — landing page
- [`privacy.html`](privacy.html) — Privacy Policy
- [`terms.html`](terms.html) — Terms of Service

Static HTML/CSS/JS, no build step. Deployed via GitHub Pages on push to `main`.

The iOS app source lives in a separate, private repository.
